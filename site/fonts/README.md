# Fonts

**Poppins** by Indian Type Foundry, Jonny Pinhorn and Ninad Kale.

Licensed under the [SIL Open Font License 1.1](https://openfontlicense.org/),
which permits redistribution — so the files are served from this repository
rather than a third-party CDN. That keeps the site free of external requests:
nothing here phones home, and no visitor is announced to another server just
for loading a typeface.

Only the latin subset is included (five weights, ~38 KB total).
